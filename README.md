# JVK Performance

Otimizador de Windows para jogos. Todo ajuste é salvo antes de ser aplicado e pode ser revertido.

## Baixar

**[⬇ Baixar a versão mais recente](https://github.com/Lucashfranco/jvk-performance-download/releases/latest)**

Na página da versão, clique em `JVKPerformance-Setup-x.y.z.exe`.

## Requisitos

- Windows 10 (versão 2004 ou mais nova) ou Windows 11, 64 bits
- Permissão de administrador para instalar

## Como instalar

1. Abra o arquivo baixado.
2. Se aparecer **"O Windows protegeu o seu PC"**, clique em **Mais informações** e depois em **Executar assim mesmo**. Esse aviso aparece com programas novos que ainda não têm reputação no Windows.
3. Siga o instalador. No fim, o app abre sozinho.
4. Em **Autenticação**, ative a sua chave ou compre uma licença.

## Desinstalar

Em **Configurações do Windows › Aplicativos**, desinstale o **JVK Performance**. O desinstalador pergunta se você quer desfazer todas as alterações antes de remover o app.
